# Diretrizes do Projeto para IA (Lovable / Claude)

## Publicação Automática de Produção (Mandatório)
- **Auto-Publish Obrigatório**: Sempre que concluir qualquer instrução, alteração de código, melhoria ou correção dentro do Lovable, você DEVE acionar a ferramenta de publicação (publish / deploy) imediatamente para atualizar a versão de produção pública em https://sistemahibridodetreinamento.lovable.app.
- **Sem Diálogos Intermediários**: Não encerre a resposta solicitando aprovação para publicar; execute a ferramenta de publicação diretamente.
- **Respeito ao Git**: O projeto está sincronizado bidirecionalmente com o GitHub. Não realize rebase destrutivo ou operações que quebrem o histórico publicado.
